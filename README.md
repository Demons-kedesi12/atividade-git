<h2>Objetivo</h2>

<p>
Desenvolver uma Calculadora em Portugol utilizando sub-rotinas,
criando uma função específica para cada operação matemática.
</p>

<ul>
  <li>➕ Soma;</li>
  <li>➖ Subtração;</li>
  <li>✖️ Multiplicação;</li>
  <li>➗ Divisão.</li>
</ul>
